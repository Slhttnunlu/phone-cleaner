# Minimal iOS Design

This branch explores a quieter, system-like visual direction while preserving the complete Phone Cleaner flow.

## Direction

- Light result and scan surfaces instead of a dominant dark hero
- Compact white category rows with subtle borders
- System-style bottom navigation without a filled active pill
- Existing green identity retained as the primary action color
- No changes to scanning, iCloud, preview, selection, or deletion behavior

The PNG previews in this directory are deterministic design renders. They mirror the branch styles; final device screenshots can replace them after the updated native development build is installed.

- `home-preview.png`: pre-scan home
- `results-preview.png`: scan result state
