# Premium iOS redesign

This directory keeps the visual direction used by the `design/premium-ios-redesign` branch.

## Design principles

- Warm white canvas with dark emerald primary surfaces
- Soft mint content surfaces and lime primary actions
- Amber only for attention and in-development states
- Strong numeric hierarchy without inventing storage percentages
- Short, honest copy and on-device privacy cues
- Motion that respects the iOS Reduce Motion preference

## Core palette

- Dark emerald: `#0E3825`
- Deep text: `#17251C`
- Soft mint: `#EAF5EE`
- Lime accent: `#DFFF55`
- Warm white: `#FCFBF6`
- Amber accent: `#F3B84B`

The concept images are design references, not application screenshots. Runtime metrics and available categories remain driven by the existing media scan.
