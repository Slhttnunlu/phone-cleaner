# Mono Editorial Design

This branch explores a typography-first, warm minimal direction while preserving the full Phone Cleaner flow.

## Direction

- Warm off-white canvas and restrained monochrome palette
- Large editorial scan headline without a surrounding card
- Black pill-shaped primary action and floating navigation
- Compact white category rows with circular utility icons
- Persistent graphite dark appearance inherited from the preferred minimal design
- No changes to scanning, iCloud, preview, selection, or deletion behavior

The previews are deterministic design renders and can be replaced with device screenshots later.

- `home-preview.png`: pre-scan home
- `results-preview.png`: scan result state
