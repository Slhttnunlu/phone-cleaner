# Minimal Grid Design

This branch keeps the calm Minimal iOS foundation while exploring a more compact dashboard.

## Direction

- Near-white canvas with a soft sage scan surface
- Two-column category grid for faster visual scanning
- Compact cards with restrained borders and clear hierarchy
- Dark charcoal primary action with limited green accents
- Persistent graphite dark appearance inherited from `main`
- No changes to scanning, iCloud, preview, selection, or deletion behavior

The previews are deterministic design renders and can be replaced with device screenshots later.

- `home-preview.png`: pre-scan home
- `results-preview.png`: scan result state
