# Soft Blue Design

This branch explores a premium utility direction while preserving the complete Phone Cleaner flow.

## Direction

- Pale blue-gray canvas with a high-contrast navy scan surface
- Calm blue interaction color and softly elevated category cards
- Floating rounded bottom navigation with a visible active state
- Persistent graphite dark appearance inherited from the first design
- No changes to scanning, iCloud, preview, selection, or deletion behavior

The previews are deterministic design renders and can be replaced with device screenshots later.

- `home-preview.png`: pre-scan home
- `results-preview.png`: scan result state
